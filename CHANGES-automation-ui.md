# Automation screen (design C)

- Header: round back button (arrow follows the layout direction), title, and a speed chip with signal bars that opens the four speeds inline.
- Each recording is a card: name, step count, trash with the existing confirm step, and a filled play button.
- Steps are shown as a connected timeline of chips: text (cut at 10 characters), Enter, Delete, and a highlighted Send chip. Only the first 8 steps are drawn, then a "+N" chip.
- New recording is a red pill pinned to the bottom; the list scrolls above it.
- New string: macro_send (en, ar).
- Not built here: the swipe-to-delete and long-press rename hints in the mockup are not implemented.
