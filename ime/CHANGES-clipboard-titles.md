
# Enter long-press = new line
- When the field has an action (Send/Search/Go/Next/Done) a short tap runs the action (fires on release); holding ~0.4s inserts a new line.
- Multiline fields get "\n"; others get Shift+Enter. Ignored while emoji/clip/translate search is active.
- Small corner mark on the Enter key shows the second function. Plain Enter keeps firing instantly.
