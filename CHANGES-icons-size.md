# Icon size and shift icon

- iconUnitOf now uses the shortest key height of the letter rows, not the narrowest icon key width. Before, Arabic had the small Omega chip among the icon keys, so its icons drew smaller than in English. Icons are also capped at 62% of their own key.
- Shift icons: off = outline arrow, once = filled arrow, caps lock = filled arrow with a bar underneath.
- Layout proposals for Enter, 123 and symbol keys are pending a choice (A, B or C).
